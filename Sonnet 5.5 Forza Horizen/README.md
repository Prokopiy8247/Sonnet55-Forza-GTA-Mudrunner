# Roamline: Open Roads - как запустить игру

Игра: оригинальный открытый мир с гонками (Unreal Engine 5.8), 10 машин, трафик, погода, день и ночь. Сделана нейросетью Claude Sonnet 5.5 для видео.

## Запуск за 3 шага (Windows)

1. Нажмите зелёную кнопку **Code -> Download ZIP** на странице репозитория (или скачайте только эту папку) и **распакуйте архив**.
2. Откройте папку `Sonnet 5.5 Forza Horizen`.
3. **Дважды щёлкните файл `PLAY_WINDOWS.bat`.**

При первом запуске файл сам распакует игру (около 1,5 ГБ, 2-5 минут, ничего нажимать не нужно). Потом игра откроется в окне. Следующие запуски - мгновенно.

Если Windows спросит про доступ к сети (брандмауэр) - нажмите **Отмена**, игре сеть не нужна. Если появилось окно "Windows защитила ваш компьютер" - нажмите "Подробнее" и "Выполнить в любом случае" (файл не подписан сертификатом).

### Что нужно от компьютера
* Windows 10 или 11 (64 бит), видеокарта с DirectX 12 (желательно уровня GTX 1660 / RTX 2060 и выше), 16 ГБ ОЗУ, около 5 ГБ свободного места.
* Если игра тормозит - закройте браузер и другие программы.

## Mac
**На Mac игра не запускается.** Сборка сделана только под Windows (Unreal Engine собирает Mac-версию только на Mac, а проект создавался на Windows-ПК). Единственный вариант - Windows-компьютер или Windows в виртуальной машине с поддержкой DirectX 12 и видеокартой (на Mac с процессорами Apple это обычно не работает хорошо). Если появится Mac-сборка, эта папка будет обновлена.

## Управление
| Действие | Клавиши |
|---|---|
| Газ / тормоз (и задний ход) | W / S или стрелки вверх / вниз |
| Руль | A / D или стрелки влево / вправо |
| Ручной тормоз | Пробел |
| Передачи вверх / вниз | E / Q |
| Смена камеры (сзади, капот, салон, бампер) | C |
| Вернуть машину на дорогу | R |
| **Выбор машины (гараж)** | **F1 или Tab** |
| Меню отладки (телепорт, время, погода, трафик) | F2 |
| **Консоль команд** | **~ (клавиша Ё)** |
| Пауза | Esc |

Геймпад тоже работает (правый триггер - газ, левый - тормоз, левый стик - руль).

### Полезные команды консоли (клавиша ~)
`help` - список команд, `cars` - список машин, `car 6` - сменить машину, `time 19` - время суток, `weather rain` - погода (clear, cloudy, rain, fog, storm), `traffic 1` - плотность трафика (0-1), `tp crossroads` - телепорт, `respawn` - вернуться на дорогу, `autodrive on 120` - автопилот (для красивых кадров).

## Что в этой папке
* `PLAY_WINDOWS.bat` - единственный файл для запуска.
* `Build/` - игра, разбитая на части (GitHub не принимает файлы больше 100 МБ). Не удаляйте.
* `Project/` - исходный код и инструменты: C++ код игры, скрипты генерации мира и текстур, скрипты Blender, документация (`DEVELOPMENT.md`, `FEATURE_MATRIX.md`, `SONNET_5.5_FINAL_REPORT.md`, `RESEARCH_NOTES.md`). Тяжёлые ресурсы Unreal (папка Content, около 2 ГБ) в репозиторий не загружены: они воспроизводятся скриптами из `Project/Tools`.

## Честно об ограничениях
Игра играбельна, но это результат одной автономной сессии нейросети. Не сделано: фоторежим, полная карта, GPS, тюнинг. Полная петля 23 км автопилотом до конца не пройдена (см. `Project/FEATURE_MATRIX.md`).

# English (short)
**Windows only.** Download the repository ZIP, extract it, open the folder `Sonnet 5.5 Forza Horizen` and double-click `PLAY_WINDOWS.bat`. The first launch unpacks the game (~1.5 GB, 2-5 min). There is **no Mac build** (the game is packaged for Windows x64 / DirectX 12 only). Keys: W/S/A/D drive, Space handbrake, C camera, R reset, **~ console**, **F1 garage**, F2 debug menu, Esc pause. If the Windows Firewall asks, click Cancel. Source code and tools are in `Project/`.
