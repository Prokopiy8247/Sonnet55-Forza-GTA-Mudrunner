## 1. Art direction вЂ” "Halcyon": faceted low-poly coastal city
- **Style:** crisp flat-shaded low-poly, chunky readable silhouettes, slight proportion exaggeration, sun-bleached pastels over deep charcoal asphalt, neon accents (magenta `#ff3d9a`, cyan `#34e0ff`, amber `#ffb347`) that glow at night. Hard normals on big flats, smooth only for round things (tyres, trunks, balls). **No image textures**: colour comes from named Blender materials (`gta_lib.PAL` / `STD`) plus Godot shaders for windows, roads, water, sky.
- **Lighting:** warm directional sun with soft shadows, procedural sky, fog haze, glow, SSAO, ACES/AgX-style tonemap; golden-hour sunsets; at night emissive windows, warm street lamps, vehicle headlights, neon signs. Rain darkens/wets roads.
- **Characters:** stylised low-poly humans (~6.5 head heights, simple hands/feet), faceted clothes, colour variation through material slots (Skin/Hair/Shirt/Pants/Shoes/Accent) + swappable hair/hat/glasses/jacket meshes.
- **UI:** dark translucent panels, cyan/magenta accents, clean sans type, rounded corners (`GC.COL_*`).
- Everything (world, vehicles, weapons, UI, VFX) must look like one game. If something looks like an engine primitive or debug stub in a final build, it is a bug.

## 8. Cross-module APIs
**Damage contract:** every damageable (CharacterBase, VehicleBase, props, animals, glass...) is in group `damageable` and implements `apply_damage(amount: float, info: Dictionary)`. `info`: `source: Node`, `type: StringName (GC.DMG_*)`, `zone: StringName (GC.ZONE_*)`, `position: Vector3`, `direction: Vector3`, `weapon: StringName`, `impulse: float`. Bullets: hitscan ray against `GC.M_BULLET`; resolve collider в†’ walk up parents to the first node in group `damageable`; call `apply_damage`. Heads/limbs resolved by hit height relative to the character (`zone`).
**CharacterBase** (core/character_base.gd, implemented): health/armor/faction/`apply_damage`/`die`/`revive`/`knockback`/`teleport_to`/`enter_vehicle`/`set_vehicle`/`is_hostile_to`; subclasses override `_on_damaged/_on_death/_on_revive`.
**CharacterRig** (Player agent, `player/character_rig.gd`, `class_name CharacterRig extends Node3D`) вЂ” the visual + procedural animation of any humanoid (player, pedestrians, police). Public API (others rely on it): `setup(variant: Dictionary)` (`body: &"A|B|C"`, `skin/hair/shirt/pants/shoes/accent: Color`, `hair: int`, `hat/glasses/jacket/vest/backpack/beard: StringName or ""`, `scale: float`), `set_locomotion(speed: float, move_dir_local: Vector3, sprinting: bool)`, `set_stance(stance: StringName)` (`stand crouch cover_low cover_high swim_surface swim_under sit_car sit_bike ladder parachute ragdoll dead`), `set_aim(active: bool, pitch: float, yaw_offset := 0.0)`, `set_weapon_pose(kind: StringName)` (`none pistol smg rifle shotgun sniper heavy melee_knife melee_bat thrown`), `play_action(action: StringName)` (`punch kick melee_swing reload hit_react jump land enter_vehicle exit_vehicle throw hands_up`), `get_hand_socket(right := true) -> Node3D`, `get_skeleton() -> Skeleton3D`, `get_head_position() -> Vector3`, `start_ragdoll(impulse: Vector3, hit_pos: Vector3)`, `stop_ragdoll()`, `look_at_point(p: Vector3)`. Target 60 fps (min 30) on RTX 5070 / Ryzen 7 5700X3D at 1080p. Caps: active traffic в‰¤ 28 (hard 40), pedestrians в‰¤ 60 (hard 90), police vehicles в‰¤ 10 + helis в‰¤ 2, wildlife в‰¤ 30, dynamic rigid-body props в‰¤ 150, ragdolls в‰¤ 8 (oldest freed). Distance tiers: near < 60 m full sim; mid 60вЂ“140 m reduced (lower tick rate, no animation, simplified physics); far > 140 m despawn/recycle (pool, reuse). No per-prop `_process`. Static world = batched/MultiMesh with visibility ranges; city built in sectors (e.g. 100 m cells) that toggle `visible`/process. Use `NodePool` for FX. Build time at boot в‰¤ ~8 s; avoid per-frame allocations (reuse arrays/dictionaries) in hot loops; stagger AI updates.

## 12. Character skeleton spec (Blender "characters" agent AND the Rig agent must both follow this exactly)
Character 1.80 m tall, origin between the feet on the ground, facing +Y (Blender) = в€’Z (Godot). `_R` = character's right = **+X side**, `_L` = в€’X side.
Rest pose = relaxed A-pose (arms hang ~20В° away from the body, palms inward), legs straight, feet pointing forward. Armature object name `Armature`, bones (name в†ђ parent; head в†’ tail in Blender metres, x,y,z with Z up; mirror x for `_L`):
```
Hips        (root)      (0,0,0.95)  -> (0,0,1.02)
Spine       <- Hips     (0,0,1.02)  -> (0,0,1.18)
Chest       <- Spine    (0,0,1.18)  -> (0,0,1.40)
Neck        <- Chest    (0,0,1.40)  -> (0,0,1.52)
Head        <- Neck     (0,0,1.52)  -> (0,0,1.80)
Shoulder_R  <- Chest    (0.03,0,1.40) -> (0.17,0,1.42)
UpperArm_R  <- Shoulder_R (0.19,0,1.40) -> (0.30,0,1.12)
LowerArm_R  <- UpperArm_R (0.30,0,1.12) -> (0.40,0,0.87)
Hand_R      <- LowerArm_R (0.40,0,0.87) -> (0.44,0,0.76)
UpperLeg_R  <- Hips     (0.09,0,0.92) -> (0.10,0,0.50)
LowerLeg_R  <- UpperLeg_R (0.10,0,0.50) -> (0.10,0,0.09)
Foot_R      <- LowerLeg_R (0.10,0,0.09) -> (0.10,0.14,0.03)

```
(+ the same `_L` bones mirrored). Total 22 deform bones; no IK/helper bones are exported. Hand sockets for weapons: the exported GLB also contains empties `HandSocket_R` (at the right palm, ~(0.43,0.04,0.78), Y pointing forward along the fingers) and `HandSocket_L`; the Rig agent attaches `BoneAttachment3D` nodes to `Hand_R/Hand_L` and re-parents weapons there. All character meshes are **skinned to this single Skeleton3D** (Godot imports one `Skeleton3D` named `Skeleton` under `Armature`). Procedural animation never relies on bone roll: it uses `Util.bone_set_model_delta` (model-space deltas on top of the rest pose). The Rig agent may create a temporary fallback skeleton from this table while the GLB is being authored.

## 13. World content seams (World-Layout vs World-Content agents)
`WorldRoot` (World-Layout agent) builds terrain, water, roads, sidewalks, markings, airport/pier surfaces, colliders, boundary, graphs, then fills `WorldLayout.lots/furniture/nature_zones/locations` and calls `CityBuilder.build(world)` (World-Content agent: `city_builder.gd`, `building_kit.gd`, `landmark_builder.gd`, `street_furniture.gd`, `nature_builder.gd`, `window_shader` resources). WorldRoot exposes `get_sector_parent(pos: Vector3) -> Node3D` (100 m cells, each toggled for visibility/process by distance) which content builders should use for everything static. Global shader parameters (`gta_night gta_wetness gta_rain gta_fog gta_time gta_sun_energy`, all float, `global uniform float gta_night;` in shaders) are registered by the `Game` autoload; `EnvironmentSystem` animates them. Street lamps/lights: content builders add emissive lamp heads plus (pooled, near-player only) OmniLights via `EnvironmentSystem` group `street_lamp` nodes (`Node3D` with meta `lamp_height`); traffic-signal heads read `WorldLayout.signal_state` and swap `SignalRed/Amber/Green` emission.

## 14. Wave-2 contracts (traffic, pedestrians, police, air/sea, interiors, garage, save, skills)
Wave-1 modules are DONE and documented in `docs/api/*.md` (world, world_content, environment, player, character_rig, vehicles, weapons, ui, audio, blender_*). Read the ones you depend on; they are the truth where they differ from older text above.

**14.1 Witnesses & reporting (Peds <-> Wanted).** `PedManager.get_witnesses(pos: Vector3, perpetrator: Node, radius := 45.0) -> Array` returns living civilian `Pedestrian` nodes within radius that have line of sight. `Pedestrian.witness(crime: StringName, pos: Vector3, perpetrator: Node, severity: float) -> bool` makes the ped react (panic / flee / cower / fight depending on personality) and returns true if it will phone the police; the phone call lasts 4-7 s (rig phone idle) and then emits `Events.crime_reported(crime, pos, perpetrator)`; the call is aborted if the ped dies / is knocked down / loses all sight and flees far. `WantedSystem` listens to `Events.crime_committed` and its derived-crime sources, asks PedManager for witnesses (none and no police in sight => no immediate wanted, but gunshots/explosions create an indirect report after a delay), and rates heat. Police units that SEE the player call `Game.sys(&"wanted").report_sighting(player_pos, officer)`. Public WantedSystem API (implemented by Police-A, used by everyone): `level:int`, `state:StringName (&"clear" &"pursuit" &"search")`, `heat:float`, `set_level(n)`, `clear()`, `add_wanted(points)`, `report_crime(crime, pos, perpetrator, seen_by_police:=false)`, `report_sighting(pos, officer:=null)`, `get_last_known_position() -> Vector3`, `get_search_radius() -> float`, `is_player_seen() -> bool`, `escape_progress() -> float`; it mirrors `Game.wanted_level/wanted_state` and emits `Events.wanted_changed / wanted_search_progress / crime_reported`.
**14.2 Police units (Police-A director <-> Police-B units).** Police-B owns `gta/code/police/police_units.gd` (`class_name PoliceUnits`, static factory: `spawn_officer(kind: StringName (&"patrol" &"swat" &"sniper"), xform) -> CharacterBase`, `spawn_patrol_car(xform, officers := 2) -> VehicleBase`, `spawn_tactical_van(xform) -> VehicleBase`, `spawn_roadblock(center, dir, level) -> Node3D`, `despawn(node)`), `police_officer.gd` (`class_name PoliceOfficer extends CharacterBase`, groups `police`,`npc`; faction `GC.F_POLICE`), `police_car_ai.gd`, `ai/combat_brain.gd` (reusable on-foot combat controller also used by gang NPCs), `hostile_manager.gd`/`gang_npc.gd` (gang/hostile NPCs, group `hostile`, faction `GC.F_GANG`). Units obey orders from the director through `unit.set_order(order: Dictionary)`: `{"mode": &"patrol"|&"pursue"|&"search"|&"hold"|&"leave", "target": Node, "pos": Vector3, "radius": float, "aggression": 0..1, "lethal": bool}`. Police-A owns `wanted_system.gd`, `police_manager.gd` (director: decides unit counts per star level, finds out-of-sight spawn points on the lane/ped graphs at least 80 m from the camera and outside its frustum, assigns orders, despawns far/idle units, creates roadblocks ahead of the player's travel direction at levels >= 3, requests heli support from the air agent's `PoliceHeliAI` when level >= 3, arrest/BUSTED rules calling `Game.player.arrest(by)`). Police-A may not depend on Police-B internals beyond PoliceUnits + set_order; Police-B may not edit the director.
**14.3 Driver NPCs & carjack (Traffic/Police <-> Peds).** Peds owns `PedManager.create_driver(vehicle: VehicleBase) -> CharacterBase` (rig seated via `vehicle.enter(driver, 0)`; returns null if the rig cannot be built) and `Pedestrian.on_carjacked(thief: Node)` (stumble out, then flee / fight / hands-up by personality). Traffic spawns vehicles with `VehicleFactory.spawn(id, xform, {"ai": true})` and asks `PedManager.create_driver()` when available. Vehicles expect AI to write `input_*` every physics frame, use `set_velocity()/place_at()` for teleports, and `set_ai_controlled(true)`.
**14.4 Air & sea.** Air/Sea agent adds `heli_vehicle.gd`, `plane_vehicle.gd`, `boat_vehicle.gd` (subclasses of `VehicleBase`) and hooks them into `VehicleFactory._build` / `VehicleDefs` (ids heli_civil heli_police plane_prop plane_jet speedboat, currently `implemented=false`). It also owns `police_heli_ai.gd` (`class_name PoliceHeliAI`: `PoliceHeliAI.spawn(pos) -> VehicleBase`, `set_target(node)`, `set_mode(&"patrol"|&"pursue"|&"search")`, searchlight, door-gunner bursts via CombatSystem ballistics) which the director calls.
**14.5 Interiors & shops.** Shops/Interiors agent owns `systems/shop_system.gd`, `systems/interior_system.gd` (`class_name InteriorSystem`; `Game.sys(&"shops")`), `systems/safehouse_system.gd`. An interior is a small room scene built from the `interiors/*.glb` props at a hidden far-away location (e.g. y = -400, x = 120*index) with its own lights; entering through a world door = fade -> `player.teleport_to` -> indoor camera limits -> `AudioSystem.set_space(&"interior")` -> exit door trigger returns to the street; interaction anchors come from nodes in groups `location_anchor` (meta location_id, landmark, radius) and `landmark_anchor` (GLB empties Door, PumpPoint_1, ...) created by World-Content. Systems-A owns Skills/Economy/Save; Garage agent owns `systems/garage_system.gd`, `phone_*.gd`.
**14.6 Save hooks.** Every system node that persists state implements `serialize() -> Dictionary` and `deserialize(data: Dictionary)`; `SaveSystem` collects them from `Game.systems` plus `Game.player.serialize()` and cash/time/weather/settings, writes JSON to `user://saves/slot_N.json` and restores after world boot (deferred 2 frames). Missing/unknown keys must be tolerated.
**14.7 Skills.** `Game.sys(&"skills")`: `get_skill01(id) -> float` (0..1), `get_skill(id) -> float` (0..100), `record(id, amount)` (use-based progress), ids `stamina shooting strength stealth driving flying lung`; benefits are applied by the consumers (player, weapons, vehicles, aircraft) via `get_skill01`.
**14.8 World facts every AI author must know.** Lane points sit +0.06 m above the road; the lane graph carries no yield/stop semantics at unsignalised junctions (stop signs are furniture only): traffic implements its own right-of-way; stop lines exist only at signals (use `WorldLayout.signal_state(sig, phase, t)`; contents' signal lenses use `ContentManager.set_signal_clock(Callable)` - traffic must call it with the clock it uses). Pedestrian crossings: `WorldLayout.crossing_open(idx, t)`. `EnvironmentSystem.headlights_wanted()` (not the old clock) decides headlights; `Game.wetness` reduces grip. Characters: `ai_accuracy` (0..1) and `knock_down(impulse, duration)` are honoured by weapons; Rig: use `CharacterVariants.make(kind, rng)`, `rig.set_locomotion` every frame, leave `auto_lod` on.
