# Mire & Iron — MudRunner-подобная игра на Unity, сделанная Claude Sonnet 5.5

Оригинальная игра про езду по грязи: машины вязнут в мягкой земле, колёса прорезают колею, есть лебёдка, броды, прицеп с брёвнами и 2-километровая карта. Игру целиком (код, физику, 3D-модели через Blender, интерфейс, звук) написал Claude Sonnet 5.5 автономно.

---

## Как запустить (3 шага, ничего устанавливать не нужно)

### 1. Скачайте проект
На странице репозитория нажмите зелёную кнопку **Code → Download ZIP** и **распакуйте архив целиком** (правый клик → «Извлечь всё» на Windows, двойной клик по архиву на Mac).
Игру нужно запускать из распакованной папки, не из окна архива.

### 2. Откройте папку `Sonnet 5.5 MudRunner`

### 3. Дважды кликните по файлу для вашей системы

| Система | Файл |
|---|---|
| **Windows 10 / 11** | `PLAY-Windows.bat` |
| **Mac** (Apple Silicon и Intel) | `PLAY-Mac.command` |

При первом запуске файл сам распакует игру (около минуты), потом откроет её. Следующие запуски — мгновенные.
Загрузка мира занимает 5–10 секунд — это нормально, в игре показывается экран загрузки.

## Если система ругается

**Windows.** Если появилось синее окно «Windows защитила ваш компьютер» — нажмите **Подробнее → Выполнить в любом случае**. Это обычное предупреждение для программ без платной подписи.

**Mac.** Первый раз macOS может сказать, что файл «нельзя открыть, так как не удалось проверить разработчика»:
1. Нажмите на `PLAY-Mac.command` **правой кнопкой (или Ctrl+клик) → Открыть → Открыть**.
2. Если игра после этого не открылась: **Системные настройки → Конфиденциальность и безопасность** → прокрутите вниз → **«Всё равно открыть»**.

Если двойной клик по `PLAY-Mac.command` вообще ничего не делает (у файла слетели права после скачивания):
1. Откройте **Терминал** (Spotlight → «Terminal»).
2. Напишите `chmod +x ` (с пробелом в конце), перетащите файл `PLAY-Mac.command` в окно Терминала и нажмите Enter.
3. Теперь дважды кликните по файлу.

> Mac-версия собрана, но автор не мог проверить её на реальном Mac. Если что-то не работает — напишите в комментариях / issue, указав модель Mac и версию macOS.

## Системные требования
* Windows 10/11 64-bit или macOS 11+ (Apple Silicon M1–M4 или Intel)
* Видеокарта с поддержкой DirectX 11/12 (Windows) или Metal (Mac) — подойдёт почти любой компьютер последних 7–8 лет; для комфортной игры нужна отдельная или современная встроенная видеокарта
* 8 ГБ ОЗУ, 1 ГБ свободного места после распаковки

## Как играть

В главном меню выберите **Free Drive — Wilderness** (большая карта 1,5 км: лес, река, болото, три маршрута) или **Free Drive — Proving Ground** (полигон: грязевые ямы, подъёмы, брод). В разделе **Scenarios** — задания с таймером и лимитом топлива.

| Действие | Клавиши |
|---|---|
| Газ / тормоз и задний ход | `W` / `S` (или стрелки) |
| Руль | `A` / `D` |
| Ручной тормоз | `Пробел` |
| Пониженная передача / повышенная | `R` |
| Полный привод | `T` |
| Блокировка переднего / заднего / центрального дифференциала | `F` / `G` / `V` |
| Лебёдка: зацепить / вытянуть / смотать | `Z` / `Q` / `E` |
| Камера | `C` (мышь — осмотр, колесо — приближение) |
| Карта | `Tab` |
| Подсказка по управлению | `H` |
| Фары | `L` |
| Вернуть машину на колёса (штраф топливом и временем) | `Backspace` |
| Пауза / меню | `Esc` |
| Быстрое сохранение / загрузка | `F5` / `F9` |

Геймпад тоже работает (стики — руль, RT/LT — газ и тормоз).

**Совет:** не едьте на полном газу в глубокую грязь — буксующие колёса копают яму. Включите пониженную передачу (`R`) и блокировки дифференциалов (`F`, `G`, `V`), узкие колёса вязнут сильнее широких, а если застряли — используйте лебёдку (`Z`).

## Для разработчиков

* Исходники Unity-проекта — в папке [`UnityProject`](UnityProject). Версия редактора: **Unity 6000.6.0f1** (URP, Input System). Откройте папку через Unity Hub → Add project, сцена `Assets/Scenes/Game.unity`.
* Сборка: меню **MudRunner → Build → Windows Player / macOS Player**.
* Документация: `UnityProject/DEVELOPMENT.md` (архитектура и физика), `FEATURE_MATRIX.md` (что работает, а что нет — честно), `RESEARCH_NOTES.md`, `SONNET_5.5_FINAL_REPORT.md` (итоговый отчёт со статистикой по токенам и времени), `Claude_Sonnet_5.5_Unity_MudRunner_BlenderMCP_Prompt.md` (исходное задание).
* Готовые сборки лежат в `Game/*.zip`.
